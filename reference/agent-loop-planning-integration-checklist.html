Agent Loop 计划接线检查清单

只在既有 Loop 的执行接缝增加计划能力；模型调用、工具执行和 Tool Result 回写仍由原 Loop 负责。

Hook新增责任必须保持不变
prepareNextTurn注入当前计划版本、就绪步骤和最近证据摘要。原始 Tool Result 仍在上下文；不反复累加全部历史计划。
beforeToolCall要求受约束工具携带 planStepId，检查步骤就绪，随后剥离字段。已有权限、重复保护、取消检查仍然生效。
afterToolCall从 Runtime 真实结果补全 stepId、toolCallId、代码版本，写入 EvidenceStore。原 Tool Result 正常回写给模型；计划快照不替代它。
shouldStopAfterTurn调用 CompletionContract 判断任务级交付条件。最大轮数、取消、预算与真实停止原因不被伪装为完成。

必须覆盖的集成测试

  1. 完整闭环：创建计划、收集证据、修订、改源码、验证、落交付文档。
  2. 受约束工具缺 planStepId：错误 Tool Result，handler 调用次数为 0。
  3. 绑定未就绪步骤：错误 Tool Result，handler 调用次数为 0。
  4. 模型输出 Final 但完成契约不满足：注入 Follow-up，不能标记 COMPLETED。
  5. 预算耗尽、取消或阻塞：保留真实停止原因，不能改写成 completed。
