LLM Gateway：统一模型调用的治理边界

Gateway 不是多转发一次 HTTP；它把模型调用协议、Provider 差异、模板、重试和观测集中在一个可治理入口。

Gateway 收口什么

能力为什么不留给每个 Agent
统一请求/响应Gateway 有自己的 Pydantic 领域协议；上层声明需求，不直接携带供应商 SDK 对象与原始请求。
Provider Adapter隔离 Base URL、密钥、模型名和 OpenAI-compatible 差异；SDK 对象不越过 Adapter。
Streaming收到一个上游 delta 就转换并转发一个下游 delta，不能先攒完整结果伪装成流式。
Prompt 模板按名称和版本集中渲染、校验变量并写入 Trace，避免稳定规则散落各 Agent。
重试与观测明确唯一重试所有者；记录 token、cost、latency、模型、模板版本和 trace。

验收不是 HTTP 200

正常文本返回统一结果；未知模型、未知模板、缺变量、合法 JSON 但 Schema 不合格均返回稳定错误。上层 Agent 不保存 Provider Key、不拼 Base URL、不自行实现供应商重试；Gateway 可以提供普通调用、流式与 Trace 查询入口。
