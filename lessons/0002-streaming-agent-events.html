Streaming：从打字机效果到 Agent 事件流

流式不让模型思考更快；它让长时间运行的 Agent 可观察、可取消、可恢复。

先量对延迟

指标含义
TTFT请求到首个非空 text.delta；首个 SDK chunk 不一定含文本。
Generation time首 token 到模型生成结束，受输出长度和 decode 影响。
E2E用户操作到 Agent 完成，包含模型、工具、Loop、存储和客户端渲染。

三层协议，不要混用

HTTP chunk 只是传输分片；SSE event 是服务端单向事件格式；模型 token 是生成单元。Provider Adapter 观察供应商流并归一为内部、版本化的 Harness Event；Loop 生产 run.started、tool.started、tool.completed、message.completed 等事实，SSE/CLI/Web 只传输和渲染，绝不把供应商 chunk 原样泄露给前端。

Run、取消与恢复

  1. 创建 Run、订阅事件、取消 Run 是三个接口；Run Store 与连接生命周期分离。
  2. 客户端断开不等于后台停止。取消经过 cancelling，传播给模型和工具；保存部分输出、最后 seq、步骤、工具状态、token 与原因。
  3. 只能在尚未产生不可重复业务事件的阶段自动重试。断线续传重放持久化 Harness Event，不重新拼 token；PostgreSQL 可保存事实，Redis 可做实时通知。
  4. Trace 记录 run、seq、模型、prompt、工具、用量和错误；测试不只看“页面会打字”，还要覆盖顺序、断线、取消、重放与终态。
