课程概念如何映射到代码

课程概念Python 实现关键规则
Plan / PlanStepPlan、PlanStep dataclass保存目标、依赖、验收标准、状态与证据引用。
EvidenceEvidence dataclass绑定 step_id、tool_call_id、artifact_version。
PlanStorestart、complete、revise模型没有直接改状态的入口。
StepVerifiercriterion_step_verifier每个 success criterion 都要有已通过证据覆盖。
CompletionContractall_steps_completed_contract任务级判断独立于单步骤完成。

从一次修复任务看代码流

start("s2")
→ 检查 s1 是否 COMPLETED

record_evidence(e2)
→ 记录 Runtime 的 target 失败事实

complete("s2", ["e2"])
→ 校验证据归属、版本和 successCriteria

revise(request)
→ 深拷贝 Plan → 替换步骤 → 重连依赖 → 检查无环 → 提交

最值得读的测试是 test_revision_rejects_cycle_without_mutating_plan：它证明候选修订有环时，当前计划版本和原步骤状态都不会改变。
